Firebase 雲端資料庫串接步驟說明

💡 已偵測到您的 Firebase 專案為 kaohfan-ymjh（並已啟用匿名登入）：
本網頁已自動支援 signInAnonymously 匿名驗證與預填 kaohfan-ymjh，您只需依下方步驟取得 firebaseConfig 即可完成串接！
  1. 步驟 1（進入專案設定）：在您目前的 Firebase 畫面左上角，點擊「⚙️ 設定」（位於「專案總覽」下方）→ 點選「專案設定」。
  2. 步驟 2（複製 firebaseConfig）：將頁面往下滑到最底部的「您的應用程式」區塊：
    • 若已有 Web 應用程式，點選「SDK 設定和配置」下的「設定 (Config)」，複製整段 firebaseConfig。
    • 若尚未建立 Web 應用程式，請點擊「</>（網頁）」圖示新增一個即可看到。
  3. 步驟 3（確認 Firestore 規則）：點擊左側選單的「Firestore」→ 上方「規則 (Rules)」分頁，確認允許登入者或公開讀寫（因您已開啟匿名使用者，以下規則可直接相容）： 
    rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if request.auth != null || true;
    }
  }
}
  4. 步驟 4（貼上設定）：您可以直接將複製的 firebaseConfig 貼在下方測試連線，或貼入本 HTML 檔案的 CONFIG.firebaseConfig 中永久保存！
